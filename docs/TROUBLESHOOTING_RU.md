# Диагностика AWG Admin

[Главная](../README.md) · [English](TROUBLESHOOTING_EN.md) · [Переменные окружения](ENVIRONMENT_RU.md) · [GitHub Container Registry](GHCR_RU.md)

## Контейнер панели сразу останавливается

На старте панель намеренно проверяет обязательные условия. Критическая ошибка выводится в журнал и процесс завершается, чтобы не оставлять бесполезно работающий контейнер.

Посмотрите журнал:

```routeros
/log/print where message~"AWG"
/container/print detail where name="awg-admin"
```

Проверяются обязательные env, подключение и пароль API, наличие AWG-контейнера, назначенные ему `envlists` и серверный режим, соответствие `AWG_SERVER_PUB` интерфейсу WireGuard, адреса интерфейса и порт. Переменные объединяются из всех списков, указанных в `envlists`.

Остановленный AWG-контейнер не мешает запуску панели: в журнал записывается предупреждение уровня ERROR, а панель продолжает работать. Если во время изменения `AWG_CLIENT_PUBS` контейнер запущен, панель перезапустит его. Если в этот момент он остановлен, конфигурация будет изменена без запуска контейнера.

Недостаточные права API — исключение: панель остаётся доступной и показывает понятную ошибку в GUI, чтобы пользователь мог исправить группу RouterOS.

## Нет подключения к API

Проверьте сервис и ограничение адресов:

```routeros
/ip/service/print where name="api" or name="api-ssl"
/user/print detail where name="awg-admin"
```

Для обычного API используются `MIKROTIK_API_SSL=no` и порт `8728`; для API-SSL — `yes` и порт `8729`. Пользователю нужны политики `read,write,sensitive,api`. Политика `sensitive` необходима для повторного получения закрытого клиентского конфига.

## AWG-контейнер не найден

По умолчанию ищется контейнер с `name` или `comment`, равным `wg-awg-server-1`:

```routeros
/container/print detail
```

Если имя другое, задайте `AWG_CONTAINER_NAME` в списке переменных AWG Admin и перезапустите панель.

## Интерфейс WireGuard не найден

Панель читает `AWG_SERVER_PUB` из назначенных proxy-контейнеру `envlists` и ищет ровно один интерфейс WireGuard с таким `public-key`:

```routeros
/container/envs/print detail
/interface/wireguard/print detail
```

Исправьте ключ или привязку. Панель не выбирает интерфейс только по имени, чтобы случайно не изменить другой сервер.

## Нельзя показать конфиг или QR

AWG Admin вызывает `interface/wireguard/peers/show-client-config`. Убедитесь, что:

- RouterOS поддерживает эту команду;
- у API-пользователя есть `read` и `sensitive`;
- peer был создан с приватным ключом в MikroTik;
- конфиг содержит `PrivateKey` клиента и `PublicKey` сервера.

## Рассинхронизация ключей

Она появляется, если peers менялись вручную или AWG-контейнер редактировался отдельно. Кнопка «Синхронизировать» записывает в `AWG_CLIENT_PUBS` текущие публичные ключи всех peers найденного интерфейса. Запущенный AWG proxy-контейнер перезапускается; остановленный остаётся остановленным.

## Технические данные ошибки

Любая известная ошибка имеет понятный текст, а раскрываемый блок содержит ответ RouterOS и код обращения. Неизвестная ошибка также не завершает контейнер. Секреты по известным шаблонам скрываются перед передачей технического текста в браузер.
