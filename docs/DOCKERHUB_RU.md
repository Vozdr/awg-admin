# AWG Admin

Полная документация и исходный код: [github.com/Vozdr/awg-admin](https://github.com/Vozdr/awg-admin)

Веб-панель управления клиентами AmneziaWG на MikroTik для серверного контейнера `ghcr.io/timbrs/awg-proxy`. Данные хранятся только в MikroTik; локальной базы и конфигов нет.

Образ: `w03zd8rc/awg-admin:latest`

Инструкции по запуску, все env и диагностика находятся в [русской документации на GitHub](https://github.com/Vozdr/awg-admin#readme).
