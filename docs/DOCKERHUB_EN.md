# AWG Admin

Full documentation and source code: [github.com/Vozdr/awg-admin](https://github.com/Vozdr/awg-admin/blob/main/README_EN.md)

A web panel for managing AmneziaWG clients on MikroTik with a server-mode `ghcr.io/timbrs/awg-proxy` container. All operational data is stored only on MikroTik; there is no local database or configuration file.

Image: `w03zd8rc/awg-admin:latest`

Setup, environment reference, and troubleshooting are available in the [English documentation on GitHub](https://github.com/Vozdr/awg-admin/blob/main/README_EN.md).
